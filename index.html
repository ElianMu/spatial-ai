Design the environment

An environment is a set of design choices: which stairs and lifts run, which doors are shut, where hindrance and affordance regions lie, where the dock and recycling station sit, and how many people work here. Every option is simulated with the full agent model and scored by how well its agents perform.

        What is real and what is approximated

        Sensors are simulated by ray casting against the building's geometry with noise; MOMO never reads the floor plan. Mapping, frontier exploration and A* planning run on MOMO's own map. Pose is estimated from noisy odometry and scan matching, but the map uses the true pose (no loop closure). The object detector returns true categories once an object is in view and unoccluded; rooms, zones and relations are inferred. MOMO has no arm.
